# OceanBase 三地延时监控大屏

这是一个基于 Vue 3 + Vite + AntV G2 + DataV 的 OceanBase 数据库三地延时监控大屏展示项目。

## 功能特性

- 📊 **实时延时监控**: 展示 OceanBase 数据库在三个地点（信息大楼、南航大厦、北京大兴）之间的复制延时
- 🗺️ **拓扑可视化**: 使用 AntV G2 绘制三地集群间的延时关系图
- 📈 **趋势分析**: 展示延时历史趋势图表
- 📋 **租户详情**: 列出各租户（电子客票、飞行计划、电子商务、航班中心）的详细延时信息
- 🎨 **DataV 装饰**: 使用 DataV 组件增强大屏视觉效果
- ⏰ **实时时间**: 显示当前系统时间

## 技术栈

- **Vue 3**: 前端框架
- **Vite**: 构建工具
- **AntV G2**: 数据可视化图表库
- **DataV Vue3**: 数据大屏装饰组件库

## 项目结构

```
oceanbase-delay-dashboard/
├── index.html          # HTML 入口文件
├── package.json        # 项目配置
├── vite.config.js      # Vite 配置
└── src/
    ├── main.js         # Vue 应用入口
    └── App.vue         # 主组件（包含所有逻辑和样式）
```

## 安装与运行

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

启动后访问 http://localhost:3000 查看大屏

### 生产构建

```bash
npm run build
```

构建产物在 `dist` 目录

### 预览生产构建

```bash
npm run preview
```

## 数据说明

项目内置了示例数据，展示了以下租户的延时信息：

| 租户名称 | 租户 ID | 应用名称 |
|---------|--------|---------|
| ets_t01 | 1000006 | 电子客票 |
| flightplan_t01 | 1000007 | 飞行计划 |
| ecs_t01 | 1000003 | 电子商务 |
| fic_t01 | 1000008 | 航班中心 |

三地集群分布：
- **信息大楼** (xxdl_main_clu01): 主集群
- **南航大厦** (nhds_standby_clu01): 备集群
- **北京大兴** (bjdx_zb_clu01): 备集群

## 自定义数据

要使用实际数据，可以修改 `src/App.vue` 中的 `rawData` 对象，或者通过 API 接口动态获取数据。

## 注意事项

- 确保 Node.js 版本 >= 16
- 生产环境建议使用 Nginx 或其他 Web 服务器部署 `dist` 目录
- 如需接入真实数据源，可修改组件中的数据获取逻辑
